# Terraform + Jenkins AWS Infrastructure Project

## Project Overview

This project demonstrates AWS infrastructure provisioning using Terraform and automation through Jenkins.

## Technologies Used

- AWS
- Terraform
- Jenkins
- Git
- GitHub
- Linux

## What I Implemented

- Created AWS infrastructure using Terraform.
- Used Terraform modules to organize infrastructure configuration.
- Created a Jenkins pipeline to automate Terraform execution.
- Integrated GitHub with Jenkins for source code management.
- Added Terraform initialization, validation, planning, and apply stages.
- Verified the provisioned infrastructure through the AWS Console.
- Maintained screenshots as project execution evidence.

## Jenkins Pipeline Stages

1. Checkout Code
2. Terraform Init
3. Terraform Validate
4. Terraform Plan
5. Terraform Apply [Action Parameters - Apply(BUILD) , DESTROY]
